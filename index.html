IT Access Request Hub

Power Apps + Power Automate + ticketing system integration · Built end to end

+

An organization-wide Power Apps solution that lets any KUB employee request access to business systems (HRIS, FMS, GIS, and others), automatically routes the request to the right system owner, and creates a corresponding ticket in the IT ticketing system — with full status visibility for the requester.

Problem

Requesting system access had no standard entry point — requests came in inconsistently across teams, with no unified way to route them, track status, or guarantee they were captured in the ticketing system. This caused delays, dropped requests, and confusion over ownership.

My role

Designed and built the solution end to end, including the routing logic and the integration with the ticketing system.

What I built

  • A Power Apps intake form where employees select the system they need access to (HRIS, FMS, GIS, and others) and submit a request
  • Power Automate flows that determine the correct owning team based on the system selected and route the request accordingly
  • An integration that automatically creates a corresponding ticket in the ticketing system — no manual re-entry required
  • In-app status tracking with a direct link from each request to its corresponding ticket
  • Automated notifications to the requester when their request is completed

Workflow

Employee selects a system and submits a request → Power Automate determines the owning team and routes the request → a ticket is auto-created → the owning team processes it → requester is notified on completion and can click through to the live ticket at any time.

Impact

  • Created a single, standardized front door for system access requests, replacing inconsistent team-by-team processes
  • Eliminated manual ticket creation for these requests entirely
  • Gave requesters self-service visibility into request status for the first time
  • Used organization-wide across X departments and X connected systems, processing approximately X requests per month

Skills: Power Apps, Power Automate, system integration, conditional routing logic, cross-team process design, organization-wide rollout

SharePoint Data Migration

Cross-departmental process design + ShareGate technical procedures

+

Designed the overarching, cross-departmental process for KUB's organization-wide SharePoint data migration across 35+ departments, and authored the technical sub-processes for executing migrations using ShareGate — while enforcing least-privilege access controls throughout.

Problem

Migrating content into a new SharePoint architecture across 35+ departments needed real coordination to avoid missed content, inconsistent execution, and access control gaps. Without a defined process, a migration at this scale risked delays, rework, and inconsistent permissions.

My role

Supported SharePoint architecture planning and led process design for the migration: created the overarching cross-departmental process to keep it on track, and separately documented the technical sub-processes for running migrations with ShareGate.

What I built

  • A cross-departmental migration roadmap covering department sequencing, engagement, milestones, and status tracking
  • Technical sub-process documentation for ShareGate, covering source-to-destination mapping, permission mapping, migration execution, and validation
  • Least-privilege access control standards enforced as part of the migration, rather than permissions carrying over by default

Workflow

Department intake and prioritization → content assessment and scoping → migration executed per the ShareGate sub-process → permissions validated against least-privilege standards → department sign-off → tracking updated, next department queued.

Impact

  • Kept a 35+ department, organization-wide migration on track using a repeatable, documented process
  • Gave the team a standardized technical procedure for ShareGate, reducing errors and rework
  • Enforced least-privilege access controls consistently across the environment
  • Migration scaled across X departments and X GB/TB of content over X months

Skills: Project management, cross-departmental coordination, process design at scale, technical documentation, SharePoint architecture, ShareGate, access governance
